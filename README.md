# K-Nearest Neighbors (KNN) Classification

This project demonstrates how to implement and visualize a K-Nearest Neighbors (KNN) classifier using Python libraries: **Scikit-learn**, **Pandas**, and **Matplotlib**.

## Objective

- Understand how the KNN algorithm works for classification tasks.
- Experiment with different values of `K`.
- Evaluate model performance.
- Visualize decision boundaries in 2D.

## Tools & Libraries

- Python
- Scikit-learn
- Pandas
- Matplotlib
- NumPy

## Dataset

We use the classic **Iris dataset**, which contains 150 samples of 3 flower species with 4 features:
- Sepal length
- Sepal width
- Petal length
- Petal width

## Steps Performed

1. Load and explore the dataset.
2. Normalize features using `StandardScaler`.
3. Split data into training and testing sets.
4. Train KNN model using different values of `K`.
5. Evaluate performance using accuracy and confusion matrix.
6. Visualize decision boundaries in 2D using only `petal length` and `petal width`.
